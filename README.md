# Volna

Volna — это Android-приложение для каталога фильмов и просмотра видеоконтента, написанное на Java с использованием компонентов Android UI. Приложение показывает подборки фильмов, предоставляет экран подробной информации по каждому элементу и позволяет открывать или скачивать видео с удалённого источника.

Этот репозиторий содержит клиентское Android-приложение и конфигурацию проекта, необходимую для сборки и запуска в Android Studio.

## Возможности

- Главный экран с несколькими разделами фильмов
- Горизонтальные списки с фильмами по категориям, например комедии и семейные фильмы
- Экран подробной информации о фильме с метаданными, описанием и постером
- Экран воспроизведения видео с использованием Android `VideoView`
- Поддержка локального скачивания видео на устройство
- Интеграция с удалённым PHP-бэкендом, который возвращает данные каталога фильмов
- Современные компоненты Android, такие как `ViewModel` и `LiveData`

## Основной сценарий работы приложения

1. Экран загрузки отображается и перенаправляет на главный экран каталога.
2. Приложение запрашивает данные о фильмах у удалённого endpoint, который предоставляет бэкенд.
3. На главном экране формируются секции с постерами и метаданными.
4. При нажатии на фильм открывается экран с подробной информацией.
5. Пользователь может открыть видео сразу или скачать его для просмотра офлайн.

## Зависимость от бэкенда

Android-приложение настроено на взаимодействие с удалённым сервисом, URL которого задан в файле:

- `VolnaApp/app/src/main/java/com/example/test_android/api/UrlConstant.java`

В проекте сейчас используется внешний хост.
Это означает, что приложение зависит от работающего API/бэкенда для получения каталога фильмов и файлов видео. Если сервер будет выключен или перемещён, приложение потребуется обновить под новый адрес.

## Предварительные требования

- Android Studio (рекомендуется последняя стабильная версия)
- JDK 8 или совместимая версия JDK для Android-проекта
- Android SDK с настроенным API 34
- Физическое устройство или эмулятор на Android 7.1+ и выше

## Начало работы

1. Клонируйте репозиторий:

```bash
git clone https://github.com/<your-username>/Volna.git
cd Volna
```

2. Откройте папку `VolnaApp` в Android Studio.

3. Дождитесь синхронизации зависимостей Gradle.

4. Подключите Android-устройство или запустите эмулятор.

5. Запустите приложение из Android Studio.

## Примечания по сборке

Приложение запрашивает следующие разрешения Android:

- доступ к интернету
- чтение и запись во внешнее хранилище

Эти разрешения указаны в манифесте и необходимы для загрузки и сохранения медиафайлов.

## Важные замечания

- Проект сейчас структурирован как Java-приложение для Android, а не как проект на Kotlin.
- В приложении есть собственный загрузчик видео и логика сохранения файлов в папку загрузок `volna`.
- Некоторые части проекта выглядят как ранние прототипы или экспериментальные UI-решения, поэтому перед production-использованием может потребоваться очистка и рефакторинг.
- Приложение рассчитано на локальную разработку и демонстрационное использование, пока не будет заменён или обновлён бэкенд.
